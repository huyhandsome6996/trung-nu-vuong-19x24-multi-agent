# Giao việc qua main

Dùng [prompt tiếp quản A–Z](../10_agent_workflow/AGENT_PROMPT.md) và [START_HERE](../START_HERE.md). Clone nhánh mặc định main; toàn bộ 30 bảng hình và tài liệu hiện hành nằm ở đó. Không clone nhánh thiết kế cũ theo log lịch sử.

Tra thiết kế ở [IMAGE_CATALOG](IMAGE_CATALOG.md), [AGENT_HANDOFF](AGENT_HANDOFF.md), registry và metadata ảnh. Ngăn 10 quản lý tác vụ, quy trình sản xuất và phục hồi.
